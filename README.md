📌 Responsive Portfolio Website

This project is a responsive portfolio-style web application built using React.js. It is designed to showcase personal information, skills, and sections in a clean and modern layout with a strong focus on usability and responsiveness.

The application features a fixed vertical sidebar navigation positioned on the left side of the screen. On larger devices, the sidebar displays both icons and page names, making navigation intuitive and user-friendly. On mobile devices, the sidebar automatically adapts to display icons only, optimizing screen space while maintaining smooth navigation.

Each navigation item dynamically updates the main content area without reloading the page, providing a seamless single-page application (SPA) experience. The layout is fully responsive and works smoothly across desktop, tablet, and mobile devices.

Responsive design for all screen sizes

This project was built to practice React fundamentals, responsive UI design, and component-based architecture while creating a personal portfolio-style website.
